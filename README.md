## 💻 Run Locally

No installation or build tools are needed.

**1. Clone the repository**
```bash
git clone https://github.com/Harshit0526/portfolio.git
cd portfolio
```

**2. Open the site**

Option A: double-click `index.html`, or open it in your browser.

Option B: run a local server (recommended):
```bash
# Python
python -m http.server 5500

# or Node.js
npx serve .
```
Then visit `http://localhost:5500`.

Option C: use the **Live Server** extension in VS Code and click "Go Live".

## 🚀 Deployment

The site is deployed on **[Vercel](https://vercel.com/)**.

1. Push the code to GitHub.
2. Go to Vercel, click **Add New → Project** and import the repository.
3. Keep the default settings, since this is a static site with no build command.
4. Click **Deploy**. Every push to `main` redeploys automatically.

It can also be hosted for free on **GitHub Pages** (Settings → Pages → select the `main` branch).

## 🎨 Customization

Want to use this as a template for your own portfolio?

1. **Content:** edit the text in `index.html` (name, about, skills, projects, education).
2. **Resume:** replace `assets/HarshitResume.pdf` with your own file (keep the same file name, or update the links).
3. **Images:** replace `viastastore-preview.png` and `og-image.png` (use 1200×630 for the social preview).
4. **SEO:** update the `<title>`, meta description, canonical URL and Open Graph tags in the `<head>`.
5. **Colours:** change the colour values in the stylesheet (the theme colour is `#060b18`).
